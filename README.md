# 一封写给你的信

一个会自己打开的信封网页：点一下信封，信封翻开、信纸抽出，文字像手写一样一个个出现，同时播放你准备的那首音乐。

整个网站就是几个文件，没有后端、没有数据库，放到 GitHub Pages 上就能给任何人打开。

---

## 一、想改信的内容？只改一个地方

打开 `app.js`，最上面是一段叫 `CONFIG` 的设置，所有能改的东西都在这里：

| 想改什么 | 改哪一行 |
| --- | --- |
| 信纸开头的称呼 | `salutation` |
| 正文内容 | `paragraphs`（一个引号里是一段） |
| 落款 | `signature` |
| 日期 | `date`（填 `null` 就是打开网页那一天） |
| 音乐文件名 | `musicFile` |
| 音量大小 | `volume`（0 到 1 之间） |
| 逐字出现的速度 | `typeSpeedMs`（数字越大写得越慢） |

改完保存，刷新网页就能看到效果。改坏了也不要紧，把内容重新写回引号里就行。

> 注意：正文里的引号要用英文的 `"`，每段结尾要有一个英文逗号 `,`，别把最后的 `];` 删掉。

## 二、想换音乐？

把音乐文件放进 `assets` 文件夹，命名为 `music.mp3`。

如果文件名不一样，要么把它改名，要么在 `app.js` 里把 `musicFile` 改成对应的路径。

## 三、想换画面风格？

打开 `styles.css`，最上面的 `:root` 里列着所有颜色。改色值就能整体换风格，比如把 `--wash-rose` 改成更浅的粉，信封就会更淡。

## 四、发布到网上（GitHub Pages）

1. 在 GitHub 上新建一个仓库，名字建议叫 `birthday-letter`，类型选 **Public**（公开），不用勾选任何初始化文件。
2. 把这个文件夹里的所有文件推送到这个仓库（这一步可以让我来做）。
3. 进入仓库的 **Settings → Pages**，Source 选 **Deploy from a branch**，Branch 选 `main`、目录选 `/ (root)`，保存。
4. 等一两分钟，链接就是 `https://你的用户名.github.io/birthday-letter/`。

拿到链接后自己先打开一次，确认信封、文字和音乐都正常，再发给你想发给的人。

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `index.html` | 网页的结构 |
| `styles.css` | 所有颜色、排版和动画 |
| `app.js` | 信的内容、动画流程、音乐控制 |
| `assets/music.mp3` | 你的音乐（需要你自己放进去） |
| `assets/paper.jpg` | 水彩纸背景，想换直接覆盖这张图 |
| `assets/icon.svg` | 浏览器标签页上的小图标 |
