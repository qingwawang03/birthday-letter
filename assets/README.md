# assets 文件夹

这个文件夹放两个东西，都是可选的——不放也能正常打开网页。

## 1. music.mp3 —— 音乐

把你准备好的音乐文件放进这个文件夹，**文件名改成 `music.mp3`**（全小写）。

放好之后刷新网页，点开信封时音乐就会自动响起，右下角会出现一个小圆钮，可以暂停和继续。

如果文件还没放进来，网页其他部分完全正常，只是右下角不会出现那个按钮。

> 如果文件超过 8MB 左右，手机上加载会有点慢，建议先压一下再放。

## 2. paper.jpg —— 水彩纸背景

文件夹里已经有一张水彩纸纹（就是现在网页上的效果）。

想换成别的话，把新图片命名为 `paper.jpg` 覆盖掉它就行，不用改任何代码。网页会自动把它铺在背景和信纸上。

建议用**浅色**的水彩纸或米色纸图片，尺寸 1600px 左右，文件越小打开越快。
